## 使用技術

こちらのアプリは

- フロントエンド:Next.js(App Router)、TypeScript、React
- スタイリング:Tailwindcss
- アニメーション:Framer Motion
- 状態管理:React Context API
- BaaS:Supabase (Authentication, PostgreSQL Database)
- 国際化(i18n):react-i18next
- デプロイ:Netlify
- ソースコード管理:Git,Github

で作成しています。

## 機能

機能としてはオリジナルルーレットの作成、テンプレートの使用、お気に入りのルーレットを保存（要ユーザ登録）、テンプレートの公開（要ユーザ登録）です。

ルーレット結果の決定は random()関数を使用しています。

ルーレットホイールの表示は canvas を使用して、random()で決定された項目が矢印の位置に来るように設定しています。

言語の翻訳は src ディレクトリ内の i18n/locales 以下にそれぞれ ja や en などのフォルダを作成し、Json ファイルで管理しています。

まだまだ勉強したてなので、こここうしたほうがいいよや、ここはどうなっているんだなど、ぜひご意見下さい。
